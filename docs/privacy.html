PRIVACY POLICY

Data collection

Wax on/Wax off does not collect, transmit, sell, or share personal data. It contains no analytics, advertising, tracking technology, account system, or third-party SDK.

Local file access

The app uses the standard macOS folder picker to request access to a folder you select. It reads local file names, sizes, types, and modification dates only to build the cleanup plan you requested. This information remains on your Mac.

A security-scoped bookmark is stored in the app's sandbox container so macOS can remember your folder choice. You can remove that bookmark at any time with Reset Folder Access in the app menu.

The app does not scan project folders. It stores optional cleanup-memory receipts containing aggregate byte counts, dates, cleanup mode, and hashed candidate identifiers. It does not store file contents or complete cleanup file lists. Use Reset Cleanup Memory to remove this local information.

Changes to files

No file is changed during analysis. The app modifies only selected eligible items after confirmation. LEFTOVERS are moved to Trash and remain recoverable until you empty Trash.

Protected personal folders such as Downloads, Desktop, Documents, Pictures, Movies, and Music are not scanned.
