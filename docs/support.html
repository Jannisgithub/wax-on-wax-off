WAX ON/WAX OFF FOR MACOS

Before cleanup

Close applications whose caches you want to review. Select a mode, choose RUN, and approve your Home folder in the macOS folder picker. Analysis is read-only.

HIGH remains limited to documented cache locations. It never scans project folders or protected personal folders such as Downloads, Desktop, Documents, Pictures, Movies, or Music. Every HIGH-only action starts unchecked, and the app recommends MID when HIGH would add less than 1 GB of immediate cleanup.

If nothing appears

The selected mode may have found no files old enough to qualify, or macOS may protect a location. Try another mode, verify the selected Home folder, and review any note shown by the app.

Reset access

Choose Wax on Wax off → Reset Folder Access, then run analysis again to select a different Home folder.

Use Reset Cleanup Memory to remove local cleanup receipts.

Understanding results

Deleted now is permanently removed cleanup data. Moved to Trash remains recoverable and does not free disk space until Trash is emptied. Available-space change is reported by macOS and can differ because apps and APFS snapshots change storage concurrently.

Contact

Open a request in the public support tracker. Do not include private file names, screenshots, or personal paths in a public support request.
